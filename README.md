# Fast Price - O Comparador de Preços de Transporte

![Fast Price Banner](https://via.placeholder.com/800x200?text=Fast+Price)

## Visão Geral

O **Fast Price** é uma aplicação web inovadora que revoluciona a forma como você escolhe seu transporte. Nosso sistema compara, em tempo real, os preços das principais plataformas de transporte – **Uber, 99 e InDrive** – para oferecer a melhor opção para seu trajeto. Além disso, o Fast Price integra informações meteorológicas e condições de trânsito em um mapa interativo, garantindo que você esteja sempre informado sobre o cenário atual e possa planejar sua viagem com segurança.

---

## Funcionalidades

### 🔍 Comparação de Preços
- **Multi-Plataforma:** Compara os preços das corridas das plataformas **Uber, 99 e InDrive**.
- **Opção Mais Econômica:** Sugere a alternativa com o menor custo, ajudando você a economizar.

### ☀️ Dados Meteorológicos
- **Clima Atualizado:** Integra dados de clima que informam se o dia está **ensolarado, chuvoso ou com tempestades**.
- **Impacto no Transporte:** Considera o clima para influenciar na estimativa de tempo e conforto da viagem.

### 🗺 Mapa Interativo de Trânsito
- **Visualização em Tempo Real:** Exibe as condições de trânsito ao longo do trajeto.
- **Rotas Coloridas:** A rota é segmentada e colorida de acordo com o fluxo de trânsito:
  - **Verde:** Trânsito fluido
  - **Amarelo:** Tráfego moderado
  - **Vermelho:** Congestionamento
- **Navegação Fácil:** Permite que você visualize rapidamente os pontos críticos do percurso.

### 💬 Feedback de Clientes
- **Avaliações Reais:** Usuários podem deixar feedbacks e avaliações das plataformas de transporte.
- **Transparência:** Ajuda a construir uma comunidade informada e colaborativa, auxiliando na escolha da melhor opção.

## Tecnologias Utilizadas

- **[React.js](https://reactjs.org/):** Framework JavaScript para construir interfaces dinâmicas e responsivas.
- **[Leaflet.js](https://leafletjs.com/):** Biblioteca para criação de mapas interativos.
- **APIs de Transporte:** Integração com serviços de precificação em tempo real.
- **APIs de Clima:** Fornece informações meteorológicas atualizadas.
- **APIs de Trânsito:** Consulta dados de tráfego para traçar rotas otimizadas.
