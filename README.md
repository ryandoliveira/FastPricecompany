# Fast Price - Comparador de Preços de Transporte

## Sobre o Projeto
O **Fast Price** é um site inovador que compara os preços das principais plataformas de transporte: **Uber, 99 e InDrive**. O objetivo é oferecer ao usuário a opção mais econômica para seu trajeto, levando em consideração não apenas os valores das corridas, mas também as condições climáticas e o trânsito em tempo real.

## Funcionalidades
### 🔄 Comparador de Preços
- Exibe os preços das viagens em tempo real das plataformas **Uber, 99 e InDrive**.
- Sugere a opção mais barata para o usuário.

### ☀️ Condições Climáticas
- Integra dados meteorológicos para informar se o clima está **ensolarado, chuvoso ou com tempestades**.
- Considera o clima como fator de impacto nos preços e no tempo estimado de viagem.

### 📊 Feedback de Clientes
- Os usuários podem avaliar sua experiência com cada plataforma.
- Exibição de opiniões para auxiliar na escolha da melhor opção.

### 🌏 Mapa Interativo de Trânsito
- Mostra em **tempo real** as condições do trânsito no percurso da viagem.
- Permite ao usuário visualizar congestionamentos e planejar melhor sua rota.

## Tecnologias Utilizadas
- **React.js** - Interface dinâmica e responsiva.
- **Leaflet.js** - Mapa interativo para monitoramento do trânsito.
- **APIs de Clima** - Coleta de dados meteorológicos.
- **APIs de Transporte** - Consulta de preços em tempo real.

## Como Rodar o Projeto
1. Clone o repositório:
   ```sh
   git clone https://github.com/seuusuario/fast-price.git
   ```
2. Acesse a pasta do projeto:
   ```sh
   cd fast-price
   ```
3. Instale as dependências:
   ```sh
   npm install
   ```
4. Inicie o servidor:
   ```sh
   npm start
   ```
5. Acesse no navegador: `http://localhost:3000`
